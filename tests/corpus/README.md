# Test corpus

Files saved by Microsoft Excel, used as real-world input for the reader and
editor tests. They are a subset of the reference files in
[rust_xlsxwriter](https://github.com/jmcnamara/rust_xlsxwriter/tree/main/tests/input)
(`tests/input/`), copyright John McNamara, used under the MIT license
(see `LICENSE_MIT` in this directory; rust_xlsxwriter is dual-licensed
MIT OR Apache-2.0). `vbaProject.bin` comes from the same project's examples.
